# Brownie

Cuisson : 25 min à 180 °C.

## Ingrédients

| Ingrédient | Quantité | Remarque |
|---|---|---|
| Chocolat noir à pâtisser | 200 g | Coupé en morceaux |
| Beurre | 100 g | Coupé en morceaux |
| Huile de noisette | 50 g | Ou huile de noix |
| Œufs | 2 | |
| Sucre | 150 g | |
| Extrait de vanille | 1 c. à c. | |
| Bicarbonate | 1 pincée | |
| Sel | 1 pincée | |
| Farine | 150 g | |
| Fruits secs | 100 g | Noix de pécan, noisettes ou noix |

## Étapes

1. **Préchauffer le four** à 180 °C.
2. **Faire fondre le chocolat** au bain-marie avec le beurre, jusqu'à obtenir un mélange bien lisse. Hors du feu, ajoutez l'huile.
3. **Fouetter les œufs :** dans un saladier, fouettez les œufs, le sucre et la vanille jusqu'à obtenir un mélange bien mousseux, puis ajoutez le mélange au chocolat.
4. **Ajouter les ingrédients secs :** incorporez le bicarbonate, le sel et la farine, et mélangez jusqu'à ce que la pâte soit homogène.
5. **Ajouter les fruits secs :** hachez-les grossièrement et ajoutez-les à la préparation. Elle doit être un peu collante sur le fouet.
6. **Verser** dans un moule carré beurré d'environ 20 cm.
7. **Enfourner** 25 minutes. Même s'il n'a pas l'air très cuit, sortez-le quand même : sinon il sera trop cuit et perdra son moelleux à l'intérieur.
