# Aubergines rôties laquées à la sauce teriyaki

Rôtissage : 30 à 40 min à 200 °C. Finition à la poêle : quelques minutes.

## Ingrédients

| Ingrédient | Quantité | Remarque |
|---|---|---|
| **Aubergines** | | |
| Aubergines | 2 | Entières |
| Huile neutre | Un filet | Pour la poêle |
| **Sauce teriyaki** | | |
| Sauce soja | 4 c. à s. | |
| Miel | 1 c. à s. | |
| Sucre de canne | 1 c. à c. | |
| Ail | 1 gousse | Hachée |
| Gingembre frais | 1 pouce (environ 2,5 cm) | Râpé, indispensable |
| **Liaison** | | |
| Fécule de maïs | ½ c. à c. | |
| Eau | 4 cl | Pour délayer la fécule |
| **Service** | | |
| Poivre | Au goût | |
| Riz | Selon l'appétit | Riz blanc |
| Cébette, sésame ou coriandre | Au choix | Pour la décoration |

## Étapes

1. **Rôtir les aubergines :** enfournez les aubergines entières à 200 °C pendant 30 à 40 minutes, jusqu'à ce qu'elles soient bien rôties et fondantes.
2. **Préparer la sauce teriyaki :** pendant la cuisson, mélangez la sauce soja, le miel, le sucre de canne, l'ail haché et le gingembre râpé.
3. **Préparer la liaison :** délayez la fécule de maïs dans les 4 cl d'eau.
4. **Ouvrir les aubergines :** sortez-les du four et coupez-les en deux dans la longueur. Manipulez-les délicatement, elles sont fragiles.
5. **Griller à la poêle :** faites chauffer un filet d'huile dans une poêle bien chaude et faites colorer les aubergines côté chair puis côté peau, quelques minutes.
6. **Laquer :** ajoutez la sauce teriyaki puis le mélange eau et fécule. Retournez régulièrement les aubergines pour bien les enrober.
7. **Réduire :** laissez la sauce réduire jusqu'à ce qu'elle devienne sirupeuse et nappante.
8. **Poivrer et servir :** poivrez, puis déposez les aubergines sur un lit de riz en les nappant de sauce.
9. **Décorer** avec de la cébette émincée, des graines de sésame ou de la coriandre.
