# Moussaka

Cuisson : 30 min à 180 °C pour les légumes, puis environ 30 min à 180 °C pour le gratin.

## Ingrédients

| Ingrédient | Quantité | Remarque |
|---|---|---|
| **Légumes** | | |
| Aubergines | 2 à 3 | En rondelles |
| Petites pommes de terre | 6 | En rondelles |
| Huile d'olive | Un filet | |
| **Sauce à la viande** | | |
| Oignon | 1 | Émincé |
| Ail | 2 gousses | Émincées |
| Viande hachée | 500 g | Bœuf, veau ou porc |
| Vin rouge | 1 verre | |
| Pulpe de tomates | 200 g | |
| Concentré de tomates | 1 c. à s. | |
| Bouillon de bœuf ou de veau | 50 cl | |
| Sucre | 1 c. à c. | |
| Feuilles de laurier | 2 | |
| Piment d'Espelette en poudre | 2 c. à c. | |
| Noix de muscade | Au goût | Râpée |
| Sel, poivre | Au goût | |
| **Béchamel fromagère** | | |
| Beurre | 70 g | |
| Farine | 70 g | |
| Lait entier | 1 l | |
| Jaunes d'œufs | 2 | |
| Ossau-iraty | 300 g | Râpé |

## Étapes

1. **Préchauffer le four** à 180 °C.
2. **Rôtir les légumes :** coupez les aubergines et les pommes de terre en rondelles, et disposez-les sur une plaque recouverte de papier sulfurisé. Arrosez d'un filet d'huile d'olive, ajoutez des épices et du sel, puis enfournez 30 minutes.
3. **Faire revenir l'oignon et l'ail** 5 à 10 minutes dans une cocotte. Réservez.
4. **Dorer la viande :** dans la même cocotte, faites cuire la viande seule jusqu'à ce qu'elle commence à dorer, puis ajoutez le mélange oignon et ail.
5. **Déglacer :** versez le vin rouge et mélangez bien. Laissez cuire quelques minutes à feu moyen.
6. **Mijoter :** ajoutez la pulpe et le concentré de tomates, la noix de muscade râpée, les feuilles de laurier, le piment d'Espelette, le bouillon, le sel et le poivre. Laissez cuire à feu doux à moyen.
7. **Préparer la béchamel :** dans une casserole, faites fondre le beurre, ajoutez la farine et mélangez. Versez le lait progressivement. Au premier bouillon, baissez le feu et ajoutez sel, poivre et noix de muscade râpée. Ajoutez la moitié de l'ossau-iraty.
8. **Monter le plat :** dans un plat à gratin, superposez dans l'ordre une couche de pommes de terre, une couche d'aubergines, la viande, une autre couche d'aubergines et la béchamel. Terminez par le reste de l'ossau-iraty.
9. **Enfourner** environ 30 minutes à 180 °C.
