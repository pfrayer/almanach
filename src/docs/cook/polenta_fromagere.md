# Polenta crémeuse au saint-nectaire, lardons fumés et chanterelles

Pour 2 à 3 personnes. Prête en 20 minutes environ.

## Ingrédients

| Ingrédient | Quantité | Remarque |
|---|---|---|
| **Polenta** | | |
| Bouillon de légumes | 30 cl | |
| Lait entier | 50 cl | |
| Polenta | 120 g | |
| Crème liquide entière | 10 cl | |
| Beurre | 1 beau morceau (environ 20 g) | |
| Saint-nectaire | 100 g | Sans la croûte, en petits dés |
| Sel, poivre | Au goût | |
| **Garniture** | | |
| Poitrine fumée | 150 g environ | Coupée en lardons |
| Champignons | 200 à 250 g environ | Idéalement des chanterelles |
| Échalote | 1 | Ciselée |
| Ail | 1 gousse | Ciselée |
| Beurre | 1 petit morceau (environ 10 g) | Pour faire briller les champignons |
| Ciboulette | Quelques brins | Ciselée, pour le dressage |

## Étapes

1. **Chauffer les liquides :** dans une casserole, versez le bouillon de légumes et le lait avec un peu de sel. Portez doucement à petite ébullition.
2. **Cuire la polenta :** versez-la en pluie fine et fouettez sans arrêt pendant 5 minutes, jusqu'à ce qu'elle épaississe bien. Ne vous arrêtez pas, sinon elle fait des grumeaux.
3. **Enrichir la polenta :** ajoutez la crème, le beurre et les dés de saint-nectaire. Laissez fondre en remuant, poivrez, goûtez et rectifiez l'assaisonnement. Réservez au chaud.
4. **Dorer les lardons :** coupez la poitrine fumée en lardons et faites-les griller à la poêle jusqu'à ce qu'ils soient bien dorés. Réservez-les.
5. **Poêler les champignons :** dans la même poêle, sans la rincer, faites dorer les champignons dans la graisse des lardons.
6. **Aromatiser :** ajoutez l'échalote et l'ail ciselés, puis le petit morceau de beurre. Laissez dorer quelques minutes pour que tout soit bien brillant.
7. **Dresser :** versez la polenta dans l'assiette, disposez les champignons et les lardons par-dessus, puis parsemez de ciboulette.
