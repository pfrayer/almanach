# Carbonade flamande

Pour 4 personnes. Préparation : 20 min. Cuisson : 3 h.

## Ingrédients

| Ingrédient | Quantité | Remarque |
|---|---|---|
| **Mijoté** | | |
| Joues de bœuf | 1,5 kg | Ou paleron, macreuse |
| Oignons | 2 | |
| Beurre | 60 g | 25 g pour les oignons, 35 g pour la viande |
| Farine | 2 c. à s. | |
| Vinaigre de vin | 2 c. à s. | |
| Moutarde forte | 2 c. à s. | |
| Thym | 5 branches | |
| Clous de girofle | 3 | |
| Cassonade | 1 c. à s. | Bombée |
| Sel | Au goût | |
| Poivre | Au goût | |
| Bière brune | 66 cl | Belge de préférence |
| **Pour finir** | | |
| Pain d'épices | 2 tranches | |
| Moutarde | 3 c. à s. | |
| Eau | Un peu | Si la sauce épaissit trop |

## Étapes

1. **Préparer les ingrédients :** coupez la viande en gros cubes. Épluchez et émincez les oignons.
2. **Faire blondir les oignons :** faites fondre 25 g de beurre dans une cocotte en fonte, faites-y blondir les oignons, puis réservez-les.
3. **Saisir la viande :** dans la même cocotte, ajoutez les 35 g de beurre restants et faites revenir les cubes de viande à feu assez vif, jusqu'à ce qu'ils soient bien colorés : cette étape donne beaucoup de goût à la sauce.
4. **Assembler :** saupoudrez de farine et mélangez. Ajoutez les oignons réservés, le vinaigre, la moutarde forte, le thym, les clous de girofle, la cassonade, du sel et du poivre. Versez la bière et mélangez.
5. **Laisser mijoter** à couvert, à feu doux, environ 2 h, jusqu'à ce qu'une fourchette s'enfonce facilement dans la viande. Selon le morceau utilisé, prolongez la cuisson de 20 à 30 min.
6. **Ajouter le pain d'épices :** tartinez les tranches de pain d'épices avec les 3 c. à s. de moutarde et posez-les sur la viande, côté moutarde vers le bas. Couvrez et laissez cuire encore 30 min : le pain d'épices se dissout dans la sauce et l'épaissit.
7. **Ajuster la sauce :** si elle devient trop épaisse, ajoutez un peu d'eau. En fin de cuisson, elle doit être nappante et la viande fondante. Servez bien chaud.

!!! tip
    Choisissez une bière brune belge, maltée et pas trop amère (Leffe Brune, Chimay Bleue, Grimbergen Brune). En Belgique, la carbonade se sert avec des frites ; elle est aussi très bonne avec des pâtes, une purée ou des pommes de terre vapeur. Comme tous les plats mijotés, elle est encore meilleure réchauffée le lendemain, et elle se congèle très bien.
